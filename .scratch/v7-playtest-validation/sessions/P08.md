### 2.1 FINDING-A01: Default Pursuer Spawn Separation (> 18.0m) Triggers Instant Contact-Break Evasion Bypass
- **TAXONOMY**: Pursuit Tension / Level Composition Bug
- **SEVERITY**: **S2 (Major Experience Degradation / Mechanics Bypass)**
- **OBSERVED**:
  In [`scrap_test_block.gd`](file:///Users/bobbyinthelobby/%7Bart/godot/scripts/prototype/scrap_test_block.gd#L83):
  Pursuer default spawn position is `Vector3(0, 0.6, -15.0)`.
  Courier bike default position is `Vector3(-1.5, 0.05, 3.0)`.
  Initial distance = `sqrt((-1.5)^2 + (0.05 - 0.6)^2 + (3.0 - (-15.0))^2) = 18.07 meters`.
  In [`scrap_test_block.gd`](file:///Users/bobbyinthelobby/%7Bart/godot/scripts/prototype/scrap_test_block.gd#L185-L194):
  ```gdscript
  if dist > 18.0:
      _contact_broken_timer += delta
      if _contact_broken_timer >= 3.0:
          current_pursuit_state = PursuitState.CONTACT_BROKEN
          await get_tree().create_timer(1.0).timeout
          current_pursuit_state = PursuitState.EVADED
          _deactivate_pursuit()
  ```
  Because `18.07m > 18.0m` on frame 1 of pursuit activation, `_contact_broken_timer` accumulates time immediately. A player mounting the bike and accelerating down the straightaway (+Z) stays > 18.0m away from the pursuer for 3 seconds. At `t = 3.0s`, pursuit ends in `EVADED` without the player ever seeing or interacting with SignalGate.
- **PLAYER_REACTION**: *"I extracted the core, hopped on the bike, and drove straight. I didn't turn or press any gate buttons. 3 seconds later the siren turned off and told me I EVADED! I bypassed the whole escape puzzle by accident!"*
- **INFERENCE**: Spawn placement creates an initial spatial distance (18.07m) exceeding the maximum pursuit tracking radius (18.0m).
- **RECOMMENDATION**: Spawn pursuer closer upon disturbance alert (e.g. `Vector3(0, 0.6, -8.0)`, initial separation 11.0m) so pursuer starts well within tracking range.

## 3. VERDICT & RECOMMENDATIONS

### VERDICT: FAIL
While pursuer speed `15.5 m/s` creates proper chase tension when pursuer starts < 18m away, **the default spawn distance bug (18.07m) allows players to evade without using SignalGate**, and **late gate triggers cause a 180° backward AI U-turn exploit**.

### ACTIONABLE FIXES FOR V7 TICKET 02.1 / TICKET 03:

1. **Fix Default Pursuer Spawn Position**:
   - Change pursuer initial spawn / activation position from `Vector3(0, 0.6, -15.0)` to `Vector3(0, 0.6, -7.0)` (initial separation ~10.0m) so `dist > 18.0m` contact break logic does not trigger on frame 1.
2. **Fix Late Gate Reroute Logic**:
   - In `_on_signal_gate_triggered()`, evaluate `pursuer.global_position.z` before setting detour waypoints:
     ```gdscript
     if pursuer.global_position.z > signal_gate.global_position.z:
         # Pursuer already passed gate before closure - do NOT backtrack!
         print("[PURSUER] Late gate trigger: Pursuer already past gate. Continuing direct chase.")
     else:
         pursuer.set_detour_path(waypoints)
     ```
3. **Signal Gate Swing Speed Tuning**:
   - Reduce `activation_time` from `0.4s` to `0.2s` and tween duration from `0.3s` to `0.2s` (total delay `0.4s` instead of `0.7s`) to reduce late overshoot window while maintaining visual weight.
